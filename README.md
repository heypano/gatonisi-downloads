# Γατονήσι (Gatonisi)

Εδώ βρίσκεται το παιχνίδι για Windows. Κατέβασε το `Gatonisi.exe` από την τελευταία έκδοση (Releases, δεξιά) και άνοιξέ
το. Την πρώτη φορά τα Windows ίσως πουν «Τα Windows προστάτευσαν τον υπολογιστή σας»: πάτα «Περισσότερες
πληροφορίες» και μετά «Εκτέλεση οπωσδήποτε». Από εκεί και πέρα το παιχνίδι ενημερώνεται μόνο του.

This is where the Windows version of the game lives. Download `Gatonisi.exe` from the latest release (Releases, on
the right) and open it. The first time, Windows may say "Windows protected your PC": click "More info", then "Run
anyway". After that the game keeps itself up to date.

Only the game's download is here; its source is private.
